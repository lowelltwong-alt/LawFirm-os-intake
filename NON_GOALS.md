# Non-Goals

The starter does not attempt to:

- automate all law-firm intake;
- process live inboxes or client data;
- determine privilege, work product, responsiveness, conflicts, client identity, legal merits, liability, valuation, or coverage;
- replace intake personnel, conflicts personnel, lawyers, pricing professionals, billing teams, or client/carrier reviewers;
- create a new ontology or universal legal matter taxonomy;
- become a generic agent framework, graph platform, vector database, or document-management system;
- create a broad MCP server;
- create a model marketplace or dynamic router;
- open matters, create iManage workspaces, send emails, docket deadlines, issue legal holds, submit budgets, or communicate with carriers;
- train or fine-tune models;
- commit real firm profiles, rates, guidelines, clients, matters, or adversaries;
- treat public court records as production-ready test data without governance, license, privacy, and retention review.

A feature is out of scope when it does not improve the quality, safety, or reviewability of the intake-to-budget evidence packet.

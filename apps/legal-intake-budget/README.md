# Legal Intake Budget Review UI

This app is the planned read-only review surface for local LawFirm OS intake run artifacts. It is not a connector, workflow owner, budget submission tool, carrier portal client, billing adapter, Exception Lake writer, or source of canonical schema authority.

## Contract

- Runtime inputs are local JSON artifacts only.
- Public data reports are review evidence only; public payloads stay in ignored cache paths.
- Human review decisions remain append-only artifacts generated by the Python CLI.
- The UI may display candidate Lake labels, blockers, missing facts, budget deltas, public-methodology status, and red-team notes.
- The UI should surface QA gates such as budget coherence, the synthetic QA bundle, fixture depth, calibration readiness, the labor/employment QA matrix, the L&E fixture family pack, the calibration starter pack, smoke, and pytest evidence from local manifests.
- The UI must not call backend mutation commands, external services, GitHub, email, billing, carrier portals, court systems, SQLite, or the Exception Lake.

## Drop-In Paths

Claude or another design agent can replace these files while preserving the contract:

- `apps/legal-intake-budget/src/App.tsx`
- `apps/legal-intake-budget/src/styles.css`
- `apps/legal-intake-budget/src/types.ts`
- `apps/legal-intake-budget/src/data-contract.ts`

The expected local artifact list and matrix guardrails live in
`src/data-contract.ts`. Demo review data lives in
`src/fixtures/demo-ui-review-data-bundle.json`,
`src/fixtures/demo-run-manifest.json`,
`src/fixtures/demo-labor-employment-qa-matrix-report.json`, and
`src/fixtures/demo-labor-employment-blocked-driver-impact-review-report.json`.

Generate a run-specific manifest with:

```bash
python -m lawfirm_os_intake build-synthetic-qa-bundle \
  --run-root .lawfirm-os-intake/smoke \
  --out-dir .lawfirm-os-intake/smoke/quality \
  --fixture-depth-manifest examples/synthetic/fixture-expansion/remaining-roadmap-holdouts.json \
  --repo-root . \
  --ui-manifest-out .lawfirm-os-intake/smoke/ui_review_manifest.json
```

That command reads local artifacts only, writes a candidate-only synthetic QA bundle, refreshes the UI manifest, and leaves missing calibration, L&E matrix, or L&E fixture family pack evidence blocked or pending.

Generate the UI data-bundle wrapper for a local run with:

```bash
python -m lawfirm_os_intake build-ui-review-data-bundle \
  --run-root .lawfirm-os-intake/smoke \
  --out .lawfirm-os-intake/smoke/ui_review_data_bundle.json
```

That bundle records which local JSON detail reports the frontend can render, with
hashes and no-write checks. It does not copy source payloads or grant mutation
authority.

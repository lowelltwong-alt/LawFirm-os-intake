# Model and Harness Routing

Model choice is routing, not allegiance. Route by work shape, failure cost, evidence availability, source sensitivity, and reversibility.

| Work | Default | Escalate when | Authority |
|---|---|---|---|
| hashing, segmentation metadata, totals | deterministic code | validator fails | none beyond code contract |
| entity/date extraction | small local extractor | source shape novel or coverage incomplete | candidate only |
| matter/posture ranking | small reasoning model | close alternatives, context conflict, high stakes | candidate only |
| evidence critique | independent small critic | blockers or worker disagreement | recommendation only |
| budget planning | deterministic template + small model | unsupported template or material uncertainty | proposal only |
| difficult ambiguity | frontier adjudicator | governed escalation triggers | proposal; human still confirms |

## Harness intensity

- **Low:** deterministic, one-pass, schema validation.
- **Medium:** one bounded model call plus independent deterministic checks.
- **High:** independent critic, alternative candidates, source coverage review.
- **Frontier:** bounded adjudication packet, no tools/writes, mandatory human review.

Risk controls authority. Harness depth cannot grant permission to act.

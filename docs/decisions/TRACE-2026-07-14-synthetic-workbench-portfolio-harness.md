# TRACE: Synthetic Workbench Portfolio Harness

An independent acceptance test rebuilds the synthetic rate-card, budget-input,
guideline-projection, actuals, rejection-and-appeal, configuration, change-package,
and regeneration-binding workbenches together. It uses one controlled synthetic
rate change and verifies every output remains candidate-only and performs no
external, Lake, SQLite, submission, matter-opening, or silent-learning write.

The harness is an evaluation surface, not a new workflow owner or runtime path.

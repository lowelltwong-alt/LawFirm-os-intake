# Contributing

Read `AI_WORK_START_HERE.md`, `AGENTS.md`, `REPO_ROLE.md`, `NON_GOALS.md`, and `docs/lawfirm-os-integration.md` before changing code.

## Pull-request requirements

Every substantive PR must state:

1. Which workflow state or contract is changing.
2. Whether observed evidence, practice context, or human-confirmed facts are affected.
3. Which sibling-repo authority is consumed.
4. Which tests and evaluation fixtures were run.
5. Whether any output, schema, prompt, model route, or human gate changed.
6. What remains prohibited.

Do not commit real firm profiles, client data, matter data, carrier guidelines, negotiated rates, credentials, or privileged material.
